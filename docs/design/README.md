# WinCareKit Design References

This folder stores the approved visual references for implementation.

- `wincarekit-logo.png`: approved application logo and brand reference.
- `wincarekit-overview-reference.jpg`: approved Overview/dashboard visual reference.

All UI work must follow the shared design system, reusable WPF controls, MVVM boundaries, virtualization rules, DPI/accessibility requirements, and the architecture constraints documented in the project issues. These images are visual references, not permission to hardcode page-specific styles.
